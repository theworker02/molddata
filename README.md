# molddata

Mold filesystem data paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/molddata/

## Install / run

```bash
git clone https://github.com/theworker02/molddata.git
cd molddata
node src/cli.js
node --test
```
